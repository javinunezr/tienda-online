# 🛍️ TiendaOnline

Una tienda en línea moderna y responsiva desarrollada con Bootstrap 5 y JavaScript.

## 📋 Descripción

TiendaOnline es una aplicación web que simula una tienda virtual donde puedes:
- Ver productos en tiempo real
- Buscar productos por nombre
- Filtrar por categorías
- Agregar productos al carrito
- Realizar compras

## 🚀 Características

- **Diseño Responsivo**: Se adapta a cualquier dispositivo (móvil, tablet, desktop)
- **Productos Reales**: Carga productos desde una API externa
- **Búsqueda en Vivo**: Encuentra productos mientras escribes
- **Carrito Dinámico**: Agrega y elimina productos fácilmente
- **Categorías**: Filtra productos por Electrónicos, Ropa y Joyería

## 🛠️ Tecnologías Utilizadas

- **HTML5**: Estructura de la página
- **CSS3**: Estilos personalizados
- **Bootstrap 5**: Framework de diseño
- **JavaScript**: Funcionalidad e interactividad
- **Fetch API**: Conexión con API de productos

## 🎯 Cómo Usar

1. **Ver Productos**: Al abrir la página, los productos se cargan automáticamente
2. **Buscar**: Escribe en la barra de búsqueda para encontrar productos específicos
3. **Filtrar**: Usa el menú "Categorías" para ver productos por tipo
4. **Agregar al Carrito**: Haz clic en "🛒 Agregar" en cualquier producto
5. **Ver Carrito**: Haz clic en "🛒 Carrito" para ver tus productos
6. **Comprar**: Presiona "Proceder al pago" cuando estés listo
